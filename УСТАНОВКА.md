# Как поставить «Клумбу» на VPS (без домена)

Сайт будет открываться по адресу вида `http://123.45.67.89` — IP-адресу вашего сервера.
Нужно около 20 минут. Ничего программировать не надо: копируете команды и вставляете.

## 1. Купите VPS

Подойдёт любой российский хостинг: **Timeweb Cloud**, **Beget**, **Selectel**, **REG.RU** и т. п.

* Операционная система: **Ubuntu 24.04** (или 22.04).
* Самый простой тариф: 1 процессор, 1–2 ГБ памяти, 10–15 ГБ диска (≈ 150–300 ₽ в месяц; многие считают посуточно —
  за неделю выйдет совсем немного).
* После создания сервера хостинг покажет **IP-адрес** и **пароль root** (или пришлёт на почту). Запишите их.

## 2. Подключитесь к серверу

* **Windows 10/11:** нажмите Пуск → введите `PowerShell` → откройте.
* **macOS:** откройте программу «Терминал».

Введите (вместо `123.45.67.89` — ваш IP):

```
ssh root@123.45.67.89
```

На вопрос `Are you sure you want to continue connecting` напишите `yes` и нажмите Enter.
Затем введите пароль root (при вводе символы не видны — это нормально) и нажмите Enter.

> Во многих хостингах есть и кнопка «Консоль» прямо в личном кабинете — можно работать там.

## 3. Установите сайт — три команды

Скопируйте и вставьте по очереди (в PowerShell вставка — правой кнопкой мыши):

```
apt update && apt install -y git
```
```
git clone -b claude/teachers-garden-v2 https://github.com/nalpax/klumba-ok10 /opt/klumba
```
```
sudo bash /opt/klumba/deploy/install.sh
```

Установщик попросит **придумать пароль администратора** (дважды). Это пароль для входа в админку сайта —
его знаете только вы. Дальше всё произойдёт само (2–5 минут): установится Node.js и nginx, сайт соберётся,
запустится и будет сам включаться после перезагрузки сервера.

В конце появится: **«Готово! Сайт работает: http://…»**. Откройте этот адрес в браузере.

> Если вместо git у вас архив с сайтом: загрузите его на сервер (например, через файловый менеджер хостинга
> или `scp klumba.zip root@IP:/opt/`), распакуйте в `/opt/klumba` и выполните только третью команду.

## 4. Настройте клумбу

1. Нажмите **«Вход»** → введите пароль администратора → откроется админка.
2. **«Учителя»** → «+ Добавить учителя». Директор уже есть. 🔑 у каждого учителя — его личный код входа
   (и карточка с QR для печати).
3. **«Коды ученикам»** → укажите количество и класс → «Сгенерировать» → «Распечатать карточки с QR».
4. **«QR-код сайта»** → скачайте картинку или распечатайте плакат.
5. **«Мероприятие»** → «Идёт посадка».

Если вы пробовали сажать цветы, пока проверяли сайт: «Мероприятие» → **«Удалить все цветы…»** → напишите `УДАЛИТЬ`.
Сами по себе цветы на настоящем сайте не появляются — только когда ученик сажает цветок по своему коду.

Большой экран для актового зала: «QR-код сайта» → **«Открыть режим экрана»** (или адрес `http://IP/?screen`).

## 5. Во время недели

* **Резервная копия** всех цветов и кодов (раз в день не помешает). На сервере:
  ```
  cp /var/lib/klumba/klumba.json ~/klumba-$(date +%F).json
  ```
  Скачать файл к себе на компьютер (команда на вашем компьютере, не на сервере):
  ```
  scp root@123.45.67.89:/var/lib/klumba/klumba.json .
  ```
* **Если что-то не открывается:** `journalctl -u klumba -n 50` покажет последние сообщения сайта;
  `systemctl restart klumba` — перезапустить сайт.
* **Обновить сайт** (если я пришлю новую версию): `sudo bash /opt/klumba/deploy/update.sh` — цветы и коды сохранятся.

## 6. После праздника — сохранить клумбу навсегда (без сервера и без вашего компьютера)

Клумба переедет на **GitHub Pages** — бесплатные серверы GitHub, где сейчас лежит демо. Ваш компьютер
сервером не становится; всё делается в браузере, минут за пять.

1. Админка → «Мероприятие» → **«Завершено»**, затем **«Скачать архив клумбы»** — скачается файл `archive.json`.
   (Если браузер назвал его `archive (1).json` — переименуйте в `archive.json`.)
   В архиве только учителя, цветы и тексты — ни кодов, ни личных пожеланий.
2. Откройте https://github.com/nalpax/klumba-ok10 и войдите в свой аккаунт GitHub.
3. Слева вверху кнопка с названием ветки (обычно `main`) → выберите **`gh-pages`**.
4. **Add file → Upload files** → перетащите `archive.json` → внизу **Commit changes**.
5. Через 1–2 минуты откройте https://nalpax.github.io/klumba-ok10/ — там ваша настоящая клумба: все цветы,
   учителя, итоги, режим большого экрана (`…/klumba-ok10/?screen`). Входа и админки нет — только просмотр.
6. Теперь VPS можно удалить в личном кабинете хостинга. Клумба останется на GitHub бесплатно и навсегда.

> QR-коды на карточках вели на адрес VPS — после его удаления они перестанут открываться. Для плаката «на память»
> сделайте новый QR на адрес `https://nalpax.github.io/klumba-ok10/` (в админке на VPS, раздел «QR-код сайта»,
> впишите этот адрес — пока VPS ещё работает).

## Вопросы

* **Браузер пишет «Не защищено».** Так бывает у всех сайтов без домена (адрес `http://`, а не `https://`).
  Работает сайт нормально, данные учеников никуда не утекают — мы их и не собираем.
* **Забыл пароль администратора.** На сервере: `rm /opt/klumba/.env && sudo bash /opt/klumba/deploy/install.sh` —
  установщик спросит новый пароль. Цветы и коды не пропадут.
* **Можно ли зайти в админку без пароля?** Нет. Пароль хранится только на сервере, в код страницы не попадает;
  после 10 неверных попыток за 15 минут вход с этого адреса блокируется.
